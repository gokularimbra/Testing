STREETRACER

Free open-world driving on real roads — no Google billing, no API key needed.

or
View mode

Get one free in ~60s at mapillary.com → log in → Developers → create an app token. No credit card. It’s saved in your browser only.

Controls & help
  • W / ↑ — accelerate  ·  S / ↓ — brake / reverse
  • A / ← & D / → — steer left / right
  • Space — handbrake  ·  R — respawn random

Top-down mode uses OpenStreetMap + Nominatim — totally free, no key, works instantly. Street-view mode uses Mapillary crowdsourced photos (free token). The original Google Street View build is still here at google.html. For the new 3D version see index.html.
